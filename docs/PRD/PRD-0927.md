# 满天星

## 需求背景

针对碎片化信息记录,需要一个工具来记录,方便查询,打标签,方便查询

## 用户故事

- 作为用户,我希望可以方便的在浏览器中记录链接,方便查询
- 作为用户,我希望可以方便的记录碎片化信息,方便查询
- 作为用户,我希望可以方便的打标签,方便查询
- 作为用户,我希望针对记录的信息可以跨端查看,例如PC,移动端
- 作为用户,我希望针对记录的信息可以跨设备查看
- 作为用户,我没有专门的后服务,没有数据库
- 这只是我自己使用,不会对外开放

## 其他

- 技术选型: Vite + Vue3 + tailwindcss
- AI给出的参考方案 “my-collector/docs/AI方案 0.1.md”
